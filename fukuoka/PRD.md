# PRD: 3박 4일 후쿠오카 여행 일정표 페이지

## 1. 개요
출발 전과 여행 중에 친구 4명이 각자 휴대폰으로 동선·예산·준비물을 한눈에 확인하는 단일 페이지 일정표.

## 2. 배경과 목적
- 처음 함께 여행 가는 친구 4명이라 서로의 기대와 일정이 아직 맞춰져 있지 않다.
- 출발 전에 동선과 예산을 한눈에 보고 **함께 정하도록** 하는 것이 목적이다.
- 여행 중에는 "오늘 어디 가지?"를 바로 확인하는 용도로 쓴다.

## 3. 사용자와 사용 환경
| 항목 | 내용 |
|---|---|
| 사용자 | 성인 4명 (처음 함께 여행하는 친구) |
| 사용 시점 | 출발 전, 여행 중 |
| 사용 기기 | 각자 휴대폰 (모바일 우선, 세로 화면) |

## 4. 여행 개요
- 목적지: 후쿠오카
- 기간: 3박 4일, 10월 출발
- 인원: 성인 4명

## 5. 필수 기능

### 5.1 날짜별 일정 (세로 타임라인)
| 일차 | 일정 |
|---|---|
| 1일차 | 오후 도착 → 캐널시티 → 나카스 포장마차(저녁) |
| 2일차 | 다자이후 텐만구 → 스타벅스 다자이후점 → 저녁 모츠나베 |
| 3일차 | 유후인 당일치기(버스 왕복) → 긴린코 호수 |
| 4일차 | 하카타역 쇼핑 → 오후 출국 |

- Day별로 구분되는 색을 사용한다.
- 각 일차는 세로 타임라인으로 위에서 아래로 순서대로 표시한다.

### 5.2 1인 예산 표
| 항목 | 금액 |
|---|---|
| 항공 | 25만원 |
| 숙소 (3박) | 18만원 |
| 식비 | 15만원 |
| 교통 | 8만원 |
| **합계** | **66만원** |

- 표 하단에 합계를 포함한다.
- 4명 총액이 필요하면 후속 검토 항목으로 둔다(현재 범위 밖).

### 5.3 준비물 체크리스트
- 여권
- 유심
- 1인 엔화 3만엔
- 우산

- 항목을 탭하면 체크/해제된다.

## 6. 디자인 요구사항
- 세로 타임라인 형태
- Day별 색 구분 (Day 1~4 각각 다른 색)
- 휴대폰 화면 폭에 맞는 단일 컬럼 레이아웃, 큰 터치 영역

## 7. 기술 제약
- HTML·CSS·JS를 담은 파일 하나(`index.html`)로 구성한다.
- 서버·빌드 도구·외부 라이브러리 없이 브라우저에서 바로 열린다.

## 8. 범위 밖 (이번 버전 제외)
- 로그인, 서버 저장, 실시간 공유
- 지도 연동, 환율 계산
- 위에 명시되지 않은 일정·예산 항목 추가

## 9. 성공 기준
- 4명이 휴대폰에서 열어 4일 일정과 66만원 합계를 스크롤만으로 파악할 수 있다.
- Day 색 구분만 보고도 몇 일차인지 알 수 있다.
- 준비물 체크가 동작한다.

## 10. 열린 질문
- 체크 상태를 새로고침 후에도 유지할지 (유지 시 localStorage 사용)
- 각 일정에 시간대를 표기할지 (제공된 자료에 시각 정보 없음)
