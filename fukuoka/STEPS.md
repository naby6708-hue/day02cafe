# 만들 순서 (STEPS)

대상: `index.html` 한 파일. 자세한 요구사항은 [PRD.md](PRD.md) 참고.

## 1단계. 뼈대
- `index.html` 생성, 모바일 viewport 설정
- 2개 섹션의 자리만 마련: 날짜별 일정 / 1인 예산 (준비물 섹션은 2단계에서 추가)
- Day 1~4 블록과 예산 표(합계 행 포함)를 내용 그대로 마크업
- 완료 기준: 스타일 없이도 일정과 예산 내용이 빠짐없이 보인다.

## 2단계. 기능
- 준비물 체크리스트 섹션 추가: 여권, 유심, 1인 엔화 3만엔, 우산
- 항목 탭 시 체크/해제 동작(JS)
- (결정 시) 체크 상태를 localStorage에 저장
- 예산 합계가 66만원으로 맞는지 확인(필요하면 JS로 계산)
- 완료 기준: 준비물 4개가 보이고 체크가 동작하며, 합계가 정확하다.

## 3단계. 디자인
- 세로 타임라인 선과 점 스타일링
- Day 1~4 색 구분 적용
- 모바일 단일 컬럼, 터치하기 쉬운 크기, 예산 표 가독성 정리
- 완료 기준: 휴대폰 폭에서 한눈에 읽히고 Day 색으로 구분된다.

## 4단계. 점검
- 휴대폰 폭(약 375px)에서 가로 스크롤·글자 잘림 확인
- PRD 필수 기능 3가지와 성공 기준 항목별 대조
- 일정·금액·준비물 내용이 자료와 일치하는지 확인
- 열린 질문(체크 유지, 시각 표기) 최종 결정
